# ✦ Calculator

A modern and responsive calculator built using **HTML, CSS, and JavaScript**, featuring a beautiful **Liquid Glass / Glassmorphism UI** inspired by modern macOS design.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear calculator
- ⌫ Delete / Backspace functionality
- ⚡ Instant calculation
- ⌨️ Keyboard support
- 🚫 Divide-by-zero error handling
- 📱 Responsive design
- 🪟 Liquid Glass / Glassmorphism interface
- ✨ Smooth hover and click animations
- 🌈 Animated background effects

## 🛠️ Technologies Used

- **HTML5** — Structure of the calculator
- **CSS3** — Styling, animations, glass effects and responsive design
- **JavaScript** — Calculator logic and user interaction
